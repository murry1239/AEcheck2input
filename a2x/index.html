A2X 0.3 AE to XML

ACI 결과에서 AE(H열 O) 사례를 ICH E2B(R3) XML로 만듭니다.

ACI와 같은 작업 폴더를 씁니다.
작업 폴더의 ACI_outputs에 있는 ACI 결과(IDBI_YYYYMMDD_ACI.xls)를 고르면, H열이 O인 행만 사례 1건 = XML 1개로 만들어 A2X_outputs에 저장합니다. 웹이나 안전성 DB에 직접 접속하지 않습니다.
  • AE명은 MedDRA 확인 후 직접 입력해야 합니다.
  • Narration은 IDBI 내용이 동일하게 입력되오니 수정이 필요합니다.
  • DB에 입력 후 확인 및 QC 하시기 바랍니다.
